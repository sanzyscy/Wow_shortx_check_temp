# Shortx Own Check

Власний діагностичний інструмент для посилання `https://shortxlinks.in/8ciL1`.

**Не містить Fyphost/adlinkfly_bypasser або інших сторонніх обхідників.** Алгоритм написаний спеціально для цього проєкту. Для запуску Chrome застосовується офіційна бібліотека Microsoft Playwright.

## Як запустити з Android

1. Відкрий у цьому репозиторії вкладку **Actions**.
2. Обери **Shortx Own Browser Check**.
3. Натисни **Run workflow → Run workflow** (лише вручну).
4. Відкрий завершений запуск і знайди **Artifacts → shortx-own-report**.
5. Переглянь `RESULT_UA.md` і `result.json`.

Скрипт не вводить логінів/паролів, не завантажує кінцеві файли та не проходить CAPTCHA. У разі виходу за межі відомого рекламного ланцюжка результат позначає як **candidate_unverified** — не підтверджений і не перевірений на безпечність URL.

**Важливо:** репозиторій публічний, тому не додавай секретів, cookies, паролів та персональних даних. Логи GitHub Actions також можуть бути публічними. Жодних інших репозиторіїв скрипт не змінює.

### Вміст

- `shortx_resolver.py` — наш алгоритм діагностики
- `tests/test_resolver.py` — автономні тести логіки
- `.github/workflows/shortx-own.yml` — одноразовий ручний запуск у GitHub Actions

Обмеження: до 10 кліків, до 225 секунд перевірки, 8 хвилин на всю job. Результат не гарантується.
